# 民族网络舆情动态态势感知大屏（第一阶段 · v2）

> **已归档**：本目录是第一阶段静态大屏，现已不再部署和维护。
> 统一大屏页面已迁移到 [`03_live_system/web`](../../03_live_system/web/)，GitHub Pages 部署的也是那一套（一套页面、两种模式）。

基于历史监测数据的动态态势大屏，以 1920×1080 为设计稿，页面自动等比缩放适配任意分辨率窗口（如 1366×768、1386×738、1536×864 等），不会出现裁剪或重叠。

## 运行方式

直接用浏览器打开 `index.html` 即可（推荐 Chrome/Edge，建议 1920×1080 分辨率全屏展示）。

> 实时版：如需数据实时接入、后台统一存储与实时刷新，请使用
> [`03_live_system`](../../03_live_system/README.md)（第二阶段实时动态态势感知系统）。

如需把大屏发给别人（对方电脑上没有本文件夹的其他文件），请发送 **`民族舆情态势感知大屏_单文件版.html`**——该文件已把图表库、地图数据、统计与评论数据全部内联，约 1.9MB，双击即可在任意电脑的浏览器中完整运行，无需联网、无需额外文件。数据更新后重新运行 `01_code_docs/scripts/build_single_html.py` 可重新打包。

## 数据说明

- 数据以 `民族团结进步促进法舆情统计最终版_非支持原话全量汇总最终版.xlsx` 为权威口径：平台维度 12,351 条、地区维度 1,586 条（含东部补测省份北京 10、天津 59、河南 27、江西 29 及省级拆分）、非支持/非肯定 305 条、监测来源 519 个、查看信息 18,295 条、少数民族语言舆情 2 条。
- 地图热力按省级行政区（31 个省级行政区）展示，每个省份直接标注舆情数量；四川 766、甘肃 228、新疆 160、青海 136、西藏 112、天津 59 等均已省级细化。
- 地图为全幅主视觉：大陆主图完整显示（黑龙江至海南岛、台湾省全部可见、无顶部裁剪），南海诸岛与九段线按规范以虚线框插图形式置于右下角并标注“南海诸岛”。
- 地图热力按 8 个地区分工组展示；青海、西藏已按省级拆分（136 / 112），四川·甘肃、内蒙古·河北·东北等未细分区域组按组合计展示。
- 右侧信息流的全部评论原话来自“非支持来源与原话（全量 216 条证据）”及明细表的“原话/评论原文”字段，未编造任何评论；按地区筛选时显示对应地区的真实原话。
- 时间趋势基于各文件明细表中“是否计入公众统计=是”的真实发布/评论日期汇总（逐条核验明细口径）。
- 高热内容榜的点赞/评论/转发数为源表记录的互动快照。

## 重新生成数据

如统计表有更新，运行 `_tools/build_data.py`（使用工作区 Python 环境）即可重新生成 `assets/data.js`。

### 原子化模式（第二阶段“报表 → 数据库”标准表）

`build_data.py` 已支持直接读取原子化标准表（含“舆情事实表 / 监测来源与查看信息 / 待清洗区”三个标准 sheet），输出结构与旧流程完全一致：

```bash
python 01_code_docs/scripts/build_data.py --atomic                  # 自动查找原子化示例表
python 01_code_docs/scripts/build_data.py --atomic "路径/库.xlsx"   # 指定表路径
ATOMIC_XLSX="路径/库.xlsx" python 01_code_docs/scripts/build_data.py
```

默认不加参数仍按 16 个报表式 Excel 的旧流程生成，两条路径互不影响。

## 模块

- 顶部：核心统计指标（数字加载动画）
- 中央：中国地图热力图（大小适配两侧面板不遮挡、整体上移为海南岛留出空间；热力采用单一红色系由深到浅，与背景明显区分；31 个省级行政区直接标注舆情数量；呼吸点偏移不遮挡数字；南海诸岛虚线框插图；区域自动轮播高亮；地图下方实时弹出当前地区的支持/非支持分布卡）
- 左侧：平台分布（大幅加高：柱尾直接标注“数量 · 占比”、舆情量排名、支持/非支持堆叠、自动轮播，高亮时显示平台详情卡，紧邻数据下方标注“代表性发言”并完整展示 1 条真实评论）、热点地区排行
- 右侧：网络舆情信息流（真实原话连续滚动、所有地区统一 28px/秒 速度，按当前地区/平台自动筛选，筛选时“恢复全部”按钮保持在面板内）、少数民族语言声音聚焦、语言分布（已移至右栏底部）
- 底部：总体态度（自动高亮）、非支持问题构成（类别自动切换）、舆情时间趋势（可播放时间轴）

监测来源数（519）、查看信息数（18,295）已在顶部核心指标中展示，不再于底部重复；平台覆盖 7 组、地区覆盖 8 组显示在底部数据说明栏。

## 多维联动

大屏按“联动剧本”自动轮播：地图高亮某地区时，地图旁弹出该地区舆情分布卡（总量/支持率/支持/问题型非支持/主要声音），底部态度构成、非支持构成、右侧信息流同步切换为该地区数据，并高亮该舆情主要来源平台；平台聚焦时同步切换对应平台的详情卡、态度构成与信息流。点击地图省份、热点排行或平台柱状图可手动锁定筛选，“暂停/继续轮播”与“恢复全部”控制自动播放。
