# 大屏“大改代码”流程（重新规划版）

> 本版依据最新参考图与最新表述**整体重写**。核心原则：**左侧是地区、右侧是平台、右下方是少数民族语言聚焦、历史时间轴放底部最左侧**；每个主板块采用**上下结构——上方为该板块分布图/信息，下方为该板块信息流随机轮播**。“当前焦点”卡片改造为**与地图轮播联动的“当前地区态度统计图”**。

## 四、详细大改代码流程

> 基底：`统计数据\民族舆情态势大屏\index.html` + `assets\data.js`；工具：`build_data.py`（数据）、`build_single_html.py`（打包）、无头浏览器截图 QA。

### 阶段 0：准备与备份（0.5 天）
1. 复制 `民族舆情态势大屏` 目录为 `_v2`（或提交 git）用于回退。
2. 确认 `data.js` 口径（12,351 / 1,586 / 31 省 / 482 原话）；如需更新先跑 `build_data.py`。
3. 建立验收基线：1920×1080 / 1536×864 / 1386×738 三档截图 + 控制台零报错 + 地图完整性检查（复用 `_tools\qa_map2.js`、`qa_scale.js`）。

### 阶段 1：布局骨架重构（index.html，1 天）
1. 主体改为三栏 + 底部四板块：
   - `#leftRail`（约 360px）：地区板块，上下两块 `#regionAttitude`（上）与 `#regionStream`（下）。
   - `#mapArea`（中央）：保留 `#map` + 呼吸点层 + 南海插图；轮播/点击联动左栏。
   - `#rightRail`（约 400px）：平台板块，上下两块 `#platformChartWrap`（上）与 `#platformStream`（下）。
2. 底部四面板（自左向右）：`#timelineChart`（历史时间轴，最左）/ `#attitudeChart`（总体态度结构）/ `#nsChart`（非支持问题构成）/ `#langFocusPanel`（少数民族语言聚焦，右下，上下两块：少语分布 + 少语样本流）。
3. CSS Grid：`grid-template-columns: 360px minmax(0,1fr) 400px`；底部 `repeat(4,1fr)`；沿用深色大屏主题。
4. 每个主板块内部为上下结构：`.panel-top{flex:1.1}`（图）+ `.panel-bottom{flex:1}`（信息流），信息流区带滚动与“随机轮播”动画。
5. 删除不再使用的面板（原右栏语言分布、原左栏热点排行等），清理对应 JS 初始化。

### 阶段 2：数据层准备（data.js 与工具函数，0.5 天）
1. 继续使用 `data.js` 现有字段：`provinces`（含省级态度字段）、`regions`（地区组态度）、`platforms`（平台统计）、`quotes`（含 `group`/`platform`/`language`/`date`/`attitude`）。
2. 新增统一过滤工具（可在 `index.html` 内实现）：
   - `quotesByRegion(group)`：`q.group === group`；
   - `quotesByPlatform(name)`：按 `PLAT_KEYS` 匹配 `q.platform`；
   - `quotesByLang(token)`：`q.language` 包含语种；
   - `topPlatformOfRegion(group)`：该地区原话中出现最多的平台（真实数据兜底，优先 `REGION_PLAT` 映射）。
3. 每个信息流提供“随机抽取 N 条 → 定时轮播（如每 4 秒换一批）”函数，保证切换平滑、条数固定。

### 阶段 3：中央地图（保留方案一实现，0.5 天）
1. 地图保持现有实现：省级红色系热力、省份数字标注、南海虚线框插图、呼吸点、`REGION_PLAT` 平台映射。
2. 轮播逻辑：地区轮播列表 = 12 个地区（含东部补测省份）；每步高亮当前地区并触发“左栏地区态度统计图”刷新。
3. 点击省份：下钻到该省态度构成（复用 `selectProvinceByName`），联动左栏态度图、信息流、平台高亮。

### 阶段 4：左栏·地区板块（上：地区态度统计图；下：地区信息流随机轮播，1 天）
1. **上：当前地区态度统计图**（由“当前焦点”卡片改造）：
   - 头部：地区名 + 舆情总量 + 支持率 + “暂停/继续轮播”按钮；
   - 图表：该地区态度构成迷你图（支持认可、中性信息、咨询疑问、担忧影响、明确批评、投诉维权、实施问题、公平争议、歧视偏见），用横向条形或数值网格呈现；数据取 `regions`/`provinces` 态度字段；
   - 底部标注：主要来源平台（`REGION_PLAT`，缺失时用 `topPlatformOfRegion` 兜底）+ 监测时间（周期 2026-07-01 至 08-05 ＋ 该地区最近样本日期 `q.date` 最大值）。
   - 联动：地图轮播/点击 → 本图实时切换，实现“地图高亮什么地区，左栏就显示该地区态度统计”。
2. **下：地区信息流随机轮播**：取 `quotesByRegion(当前地区)` 随机抽取 5–8 条真实原话轮播；无原话时显示“该地区暂无可展示样本”；每条显示“平台｜地区 + 态度标签 + 原话”。

### 阶段 5：右栏·平台板块（上：平台分布图；下：平台信息流随机轮播，1 天）
1. **上：平台舆情量分布图**：沿用方案一堆叠柱状图（支持/非支持/中性分段 + 柱尾“数量 · 占比”），7 大平台组；自动轮播高亮；点击切换当前平台。
2. **下：平台信息流随机轮播**：取 `quotesByPlatform(当前平台)` 随机抽取 5–8 条真实原话轮播；随平台轮播/点击同步切换。

### 阶段 6：底部板块（1 天）
1. **① 历史时间轴回放（最左侧）**：沿用方案一折线图（逐条核验明细口径）+ 播放/暂停播放头；增强：播放头对应日期联动地区/平台样本（按 `q.date` 过滤）。
2. **② 总体态度结构（环图）**：数据取 `D.attitude.macro`（支持 11,930/中性 55/参与建议 61/非支持 305），环图中心显示支持率，图例在侧（方案二 ring-panel 布局移植）。
3. **③ 非支持问题构成（条形图）**：沿用方案一横向条形图（8 类，全国口径 305）。
4. **④ 少数民族语言聚焦（右下）**：上下结构——上：少语分布与聚焦卡（维吾尔语/彝语真实样本、藏语普法监测记录等）；下：少语样本信息流（按 `quotesByLang` 轮播）。

### 阶段 7：集中式联动与自动轮播（1 天）
1. 建立统一状态：`state = { region, platform, language, timeline }`，所有板块订阅刷新（替代散落的 `filter/playing/focusIdx`）。
2. 联动矩阵：
   - 地图轮播/点击省份 → `state.region` → 左栏态度统计图（含平台/时间标注）+ 地区信息流 + 地图高亮 + 平台映射高亮（`REGION_PLAT`）；
   - 平台分布图点击/轮播 → `state.platform` → 右栏平台信息流 + 平台详情信息；
   - 少语聚焦卡/样本流 → `state.language` → 少语样本流切换；
   - 时间轴播放 → `state.timeline` → 播放头日期显示 + 样本/信息流按日期过滤。
3. 自动轮播顺序：地区（12 个）→ 平台（7 组）→ 少语 → 时间轴播放，统一间隔（6–7 秒/步）；“暂停/继续轮播”全局控制，人工讲解时可固定。

### 阶段 8：数据与打包（0.5 天）
1. 数据仍由 `build_data.py` 生成 `data.js`；无后端依赖。
2. 更新 `build_single_html.py` 重新生成单文件版（内联 ECharts/地图/数据）。
3. 同步更新 README 与“态势图模块功能与联动说明”。

### 阶段 9：验收（0.5 天）
1. 三档分辨率截图 + DOM 几何检查：无重叠、无溢出、无滚动条（复用 `qa_scale.js`）。
2. 地图完整性检查：漠河/海南/台湾/南海插图/虚线框、省份数字标注、热力色阶（复用 `qa_map2.js`、`qa_heat.js`）。
3. 上下结构检查：左栏（地区态度图+地区流）、右栏（平台分布+平台流）、右下（少语分布+少语流）均正常渲染与轮播。
4. 联动回归：地图轮播→地区态度图、平台轮播→平台流、少语→少语流、时间轴→样本过滤均同步刷新。
5. 数据核对：KPI、地区/平台/语言统计与 Excel 一致；信息流全部为真实原话。
6. 单文件版异地打开验证（复制到其他目录，零报错）。

## 五、风险与假设

- 参考图为版式示意，本流程按“左地区/右平台/右下少语/底部最左时间轴 + 上下结构”落地；板块标题如需逐字还原图中文字，请提供图中文字或更高清图，可在阶段 1 微调。
- 底部中间两块（总体态度结构、非支持问题构成）为需求文档与前述讨论保留的模块，置于底部②③；如需移除或换位可再说明。
- 时间点过滤样本依赖原话日期字段 `q.date`，部分原话无日期时默认不参与时间过滤。
- 信息流“随机轮播”统一间隔、固定条数、平滑过渡，避免信息乱跳；涉及地图/信息流联动时以真实数据为准，不编造样本。
