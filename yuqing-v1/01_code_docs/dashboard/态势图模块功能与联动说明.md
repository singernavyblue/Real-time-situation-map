# 态势图模块功能与联动说明

当前这版态势图围绕“全局总览、区域分布、平台分布、语言结构、时间变化、原话样本”六个层面展开，核心目标是把舆情态势从总量、结构、趋势和证据四个维度同时呈现出来，便于快速研判与汇报展示。

## 一、主要模块功能

- 总览指标：顶部展示平台维度公众意见总量（12,351 条）、可明确归属地区公众意见（1,586 条）、支持认可（11,930 条，96.6%）、非支持/非肯定（305 条）、监测来源数（519 个）、查看信息数（18,295 条）等核心指标，用于先快速把握整体规模和结构。
- 总体态度结构：通过横向条形图展示整体态度分布（支持认可、中性信息、参与建议、问题型/非支持、其他待分类），并支持分段自动高亮，便于判断支持、非支持、中性等态度的结构占比。
- 语言分布：通过条形图展示平台维度的语种或表达类型占比（中文/普通话 12,349 条、维吾尔语/文 1 条、彝语/文 1 条），并辅以“少数民族语言声音聚焦”卡片展示维吾尔语、彝语、藏语等真实监测记录，帮助判断内容来源和表达结构。
- 全国地图热力：以中国地图展示 31 个省级行政区的热度分布，采用单一红色系由深到浅（数值越高颜色越亮），各省份直接标注舆情数量；南海诸岛以虚线框插图完整呈现；支持当前地区高亮与热点呼吸闪烁。
- 平台舆情量排行：以横向堆叠柱状图展示 7 大平台组的舆情量排名（柱尾标注“数量 · 占比”，并按支持/非支持/中性分段着色），自动轮播高亮，方便识别主要传播阵地。
- 非支持问题构成：拆解非支持类内容的主要问题类型（咨询疑问、担忧影响、明确批评、投诉维权、实施问题、公平争议、歧视偏见等），类别自动切换高亮，帮助定位争议点。
- 历史时间轴：以折线图展示历史趋势变化（按逐条核验明细口径汇总），支持播放/暂停，播放头按真实日期逐日推进，用来观察不同时间点的热度起伏。
- 历史原话动态流：右侧信息流持续滚动展示 482 条已核验的真实原话（含非支持证据全量 216 条），并可按当前地区、平台或语言自动筛选，作为态势分析的证据层。
- 地区样本、平台样本：地图下方地区弹窗卡展示当前地区的总量、支持率、支持认可数、问题型/非支持数及主要声音；平台详情卡展示当前平台的数量、占比、支持率、非支持、主要态度及代表性真实发言，便于人工核验和汇报引用。
- 当前焦点卡片：地图顶部“当前联动”标识与地区弹窗卡共同构成整屏的状态中枢，集中展示当前轮播到的地区或平台及关键指标。

## 二、联动效果

- 点击地图上的省份，会同步切换当前地区（并下钻到该省的态度构成），联动刷新地图高亮、地区弹窗卡、总体态度与非支持构成、原话信息流，并自动高亮该地区的主要来源平台（如四川·甘肃→快手、新疆→微信公众号/视频号、内蒙古等→抖音）。
- 点击平台排行中的某一项，会切换当前平台，联动刷新平台详情卡、总体态度与非支持构成，并将原话信息流切换为该平台的代表性原话。
- 点击语言卡片或语种条目，会切换当前语言焦点，并刷新相关样本展示（信息流按语言筛选、语言聚焦卡片同步高亮）。
- 时间轴支持播放/暂停，播放头按真实逐日数据推进，播放期间当前日期与当日样本量实时显示。
- 页面支持自动轮播地区、平台、语言、态度与非支持类别，适合大屏展示；同时提供“暂停/继续轮播”与“恢复全部”按钮，方便人工讲解时临时固定画面。

## 三、整体效果

- 这套设计实现了“总量看全局、地图看区域、图表看结构、语言看构成、时间轴看趋势、样本看证据”的完整链路。
- 整体上既能用于领导汇报时的宏观展示，也能用于研判时的细节下钻，做到从概览到证据的快速切换。
