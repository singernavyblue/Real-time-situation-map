# 统一数据字段规范（第一阶段 ↔ 第二阶段通用）

> 第一阶段历史数据按本规范入库；第二阶段各平台采集程序抓到的数据也写入相同字段。
> 含义：**每条舆情记录** = 一条公众意见（评论/帖子/视频正文等），不是一篇报道。

| 序号 | 统一字段 | 类型 | 必填 | 第一阶段来源（Excel 常用列名） | 说明 |
| --- | --- | --- | --- | --- | --- |
| 1 | uid 唯一编号 | 文本 | 是 | 序号 / 数据编号 | 系统自动生成或外部传入，全库唯一 |
| 2 | collected_at 采集时间 | 时间 | 是 | 采集日期 / 采集时间 | 采集程序写入，格式 `YYYY-MM-DDTHH:MM:SS` |
| 3 | published_at 发布时间 | 时间 | 否 | 发布日期 / 评论日期 / 发布时间 | 平台原始时间；无法获取可为空 |
| 4 | platform 平台 | 文本 | 是 | 平台 / 平台或网站 | 原始平台名，系统自动归组 |
| 5 | source 具体来源 | 文本 | 否 | 来源账号/栏目 / 来源网站 | 采集入口/栏目 |
| 6 | account 账号 | 文本 | 否 | 账号或栏目名称 / 账号名称/发布单位 | 发布者昵称/账号 |
| 7 | text 正文 | 文本 | 是 | 评论原文 / 原文证据摘录 / 中文译文 / 原话 | 评论、帖子或视频文本 |
| 8 | url 原始链接 | 文本 | 否 | 原始链接 / 来源链接 | 证据可回溯 |
| 9 | region 地区 | 文本 | 否 | 涉及地区 / 统计地区 / 地区大类 | 地区组或具体地名 |
| 10 | province 省份 | 文本 | 否 | 省份 / 涉及地区（省级） | 地图热力用 |
| 11 | city 城市 | 文本 | 否 | 城市 | 下钻用 |
| 12 | ip_location IP属地 | 文本 | 否 | IP属地 / IP | 平台展示的属地 |
| 13 | language 语言 | 文本 | 否 | 原始语言 / 语言 | 自动标记是否少数民族语言 |
| 14 | attitude 总体态度 | 文本 | 否 | 意见类型 / 态度类别 | 支持认可/中性/咨询疑问/担忧影响/明确批评/参与建议等 |
| 15 | issue_category 具体问题类别 | 文本 | 否 | 态度类别（细分） | 咨询/担忧/批评/投诉/实施/公平/歧视等 |
| 16 | likes 点赞量 | 整数 | 否 | 点赞量 / 点赞 | 互动快照 |
| 17 | comments 评论量 | 整数 | 否 | 评论量 / 评论 | 互动快照 |
| 18 | shares 转发量 | 整数 | 否 | 转发量 / 转发 | 互动快照 |
| 19 | is_key 是否重点舆情 | 0/1 | 否 | 是否重点 / 高热 | 高热内容自动标记 |
| 20 | notes 其他备注 | 文本 | 否 | 备注 / 复核说明 | 人工核验、模拟标记、待复核原因等 |

## 系统自动补充的字段

| 字段 | 说明 |
| --- | --- |
| platform_group | 平台归组（微博/热榜、抖音等、快手、小红书/豆瓣、知乎/B站/百度知道、贴吧/头条/新闻、微信/视频号、其他） |
| attitude_bucket | 态度大类（support / neutral / suggest / non_support / other），统计合并用 |
| is_minority | 是否少数民族语言（0/1） |
| is_relevant | 是否命中民族相关关键词（0/1） |
| status | accepted（进入统计）/ pending（待复核）/ rejected（排除） |
| origin | history（历史迁移）/ simulator（模拟演示）/ file_watcher（文件导入）/ api（接口）/ 平台采集器名称 |

## 文件导入格式示例（inbox/ 目录）

JSON：
```json
{
  "records": [
    {
      "发布时间": "2026-08-14 09:30:00",
      "平台": "微博",
      "账号": "示例账号",
      "正文": "民族团结进步促进法落地后，本地反响积极",
      "地区": "四川",
      "省份": "四川",
      "语言": "中文",
      "总体态度": "支持认可",
      "原始链接": "https://weibo.com/example",
      "点赞量": 123
    }
  ]
}
```

CSV（表头用上面的中文列名）：
```csv
发布时间,平台,账号,正文,地区,省份,语言,总体态度,原始链接,点赞量
2026-08-14 09:30:00,微博,示例账号,民族团结进步促进法落地后，本地反响积极,四川,四川,中文,支持认可,https://weibo.com/example,123
```

## 微博第三方导出文件格式（data/weibo_exports/ 目录）

从微博导出工具 / 第三方采集器 / 人工整理得到的文件直接放进 `data/weibo_exports/`，
`collect.py weibo` 会自动按 24 字段转换并入库。列名兼容常见写法：

CSV 示例（导出工具常用列名）：
```csv
发布时间,微博正文,发布人,点赞数,评论数,转发数,来源,IP属地,总体态度,原始链接,备注
2026-08-14 09:30:00,支持民族团结进步促进法，各民族要像石榴籽一样紧紧抱在一起。,@示例用户A,328,56,12,微博客户端,四川,支持认可,https://weibo.com/example/1,编造示例
```

JSON 示例：
```json
{
  "records": [
    {
      "发布时间": "2026-08-14 10:15:00",
      "微博正文": "担心促进法在基层落实不到位，希望能有监督渠道。",
      "发布人": "@示例用户B",
      "点赞数": "2.1万",
      "评论数": 368,
      "转发数": 45,
      "来源": "微博国际版",
      "地区": "西藏",
      "城市": "拉萨",
      "语言": "藏语",
      "总体态度": "担忧影响",
      "备注": "编造示例"
    }
  ]
}
```

也可直接用统一字段名（唯一编号 / 采集时间 / 发布时间 / 平台 / 平台组 / 具体来源 / 账号 / 正文 /
原始链接 / 地区 / 地区组 / 省份 / 城市 / IP属地 / 语言 / 是否少数民族语言 / 总体态度 /
具体问题类别 / 点赞量 / 评论量 / 转发量 / 是否重点 / 是否计入统计 / 备注）。
