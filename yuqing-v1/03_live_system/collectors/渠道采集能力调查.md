# 各渠道实时采集能力调查表

> 用途：判断哪些渠道可以实时接入、哪些可以准实时更新、哪些暂时只能人工补充。
> 完成方式：每个平台/地区/语言方向负责人填写一张下表；能确定的写确定结论，不能确定的写“待确认”。

## 一、17 项必答问题（统一模板）

1. 负责的平台/网站名称
2. 是否需要登录
3. 是否可以持续采集
4. 目前采用什么方式采集（人工 / Python爬虫 / 采集器 / API / 其他）
5. 最快多久能够更新一次（实时 / 每小时 / 每天 / 人工定期）
6. 能否获取发布时间
7. 能否获取评论正文
8. 能否获取原始链接
9. 能否获取账号名称
10. 能否获取帖子/视频标题
11. 能否获取点赞量
12. 能否获取评论量
13. 能否获取转发量
14. 能否获取省份、城市、IP属地等地理信息
15. 能否识别评论使用的语言
16. 是否能够长期稳定运行
17. 是否存在验证码 / 登录失效 / 反爬 / 风控 / 频率限制 / 账号封禁等问题

## 二、基于第一阶段数据已知的信息

| 平台/渠道 | 第一阶段已具备字段 | 已知限制 | 建议接入方向 |
| --- | --- | --- | --- |
| 微博/热榜 | 发布时间、平台、账号、正文、涉及地区、点赞/评论/转发、语言 | 热榜只有话题+热度值，无逐条正文；开放平台搜索需高级权限 | 已接入：热榜公开接口“5-10分钟”；第三方导出文件“每天”；开放平台 API 待资质 |

| 贴吧/头条/新闻评论 | 汇总统计 | 渠道分散 | 检索式“人工定期” |
